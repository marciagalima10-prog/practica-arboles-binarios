## Estructura

```
practica_arboles/
├── arbol_bst.py   # Clases Nodo, ArbolBST, OpcionMenu y funciones
└── main.py        # Pruebas de las 20 actividades
```

## Cómo ejecutar

```bash
python main.py
```

## Actividades

**Parte I – Fundamentos**
1. Nodo de árbol binario
2. Inserción en BST
3. Recorridos preorden, inorden y postorden
4. Búsqueda de un valor
5. Valor mínimo y máximo
6. Altura del árbol
7. Conteo de nodos
8. Conteo de hojas

**Parte II – Manipulación intermedia**
9. Eliminación de nodos (sin hijos, un hijo, dos hijos)
10. Verificar si dos árboles son idénticos
11. Árbol espejo
12. Recorrido por niveles (BFS)
13. Nodos con exactamente un hijo
14. Validación de BST

**Parte III – Aplicaciones**
15. Suma de todos los nodos
16. Caminos de la raíz a las hojas
17. Nivel (profundidad) de un nodo
18. Construcción desde recorridos inorden y preorden
19. Balanceo de un BST
20. Menú jerárquico (representación hijo izquierdo – hermano derecho)
